Font Awesome's license and attribution terms are documented at <https://fontawesome.com/license/free>.

The bundled files are local copies from the versioned [`FortAwesome/Font-Awesome` 6.7.2 `svgs/solid` directory](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/solid). Each SVG retains its upstream source and license comment. No icon is downloaded at runtime.

`toothbrush.svg` uses the official `tooth.svg` artwork as a semantic alias: Font Awesome Free 6.7.2 does not include a toothbrush glyph. The configuration keeps the established `toothbrush` ID so existing calendars continue to validate. All other SVG files use the matching upstream icon ID.
